# Feature inventory

## Available foundation

- Portable feedback item, board, status, vote, comment, event, merge, and
  adapter contracts.
- Transition and merge validation with unit tests.
- Convex component schema/function scaffold and host-wrapper pattern.
- React theme/provider/card/form primitives.
- CLI dry-run project detection and safe generated-file manifest.

## Planned modules

| Module | Capabilities |
| --- | --- |
| Feedback | boards, voting, comments, moderation, labels, attachments, imports, analytics |
| Triage | inbox, filtering, keyboard actions, assignment, saved views, merges, audit log |
| Portal | branding, localization, accessibility, SEO, custom domains, embedded views |
| Roadmap | configurable status lanes, public/private layouts, prioritization |
| Updates | changelog, subscriptions, RSS, release notifications, update bell |
| Capture | contextual launcher, metadata, screenshot annotation/redaction, consent |
| Surveys | NPS/CSAT, targeting, segments, frequency caps, response analytics |
| Integrations | webhooks, email, Slack, Discord, issue trackers, CRM, automation tools |
| Support | help center, AI answers, omnichannel inbox, SLAs, workflows, reporting |

All planned modules are optional and must be usable without a central service.
